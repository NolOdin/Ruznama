Чтобы установить приложение на ваш iPhone:

  1. Нажмите кнопку Поделиться в нижней панели браузера.
  2. Прокрутите вниз и выберите «На экран "Домой"» (Add to Home Screen).
  3. Нажмите «Добавить» в правом верхнем углу.
